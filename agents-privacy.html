Privacy Policy

Last updated: October 2026

Who uses these apps

SAKO Agent and Walle Agent are used only by their owner, Giorgi Sakandelidze, to manage his own YouTube channels (SAKO Gaming and WalleGameplay).

What data they access

With the owner's Google sign-in, the apps use the YouTube Data API and YouTube Analytics API to read and update the owner's own videos, playlists, comments and channel statistics.

Where data is kept

Sign-in tokens and video data are stored only on the owner's own computer. Nothing is sold, shared with third parties or used for advertising.

Google API Services

The apps' use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be removed at any time at myaccount.google.com/permissions.
